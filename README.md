# ARP Angular

Angular client library for the Alxarafe Resource Platform (ARP).

Provides reusable integration with ARP contracts and backends, using `@alxarafe/ui-runtime` for declarative CRUD interfaces.

**Status:** Initial development. Not yet released.

## Architecture

- **ARP Contract:** Defines the platform's technology-independent contracts.
- **ARP Angular:** Interprets ARP resources and orchestrates client operations.
- **Angular UI Runtime (AUR):** Provides reusable visual components, forms, grids and editing capabilities.
- **Consumer applications:** Integrate ARP Angular and implement their own application-specific behavior.

## Package

Planned npm package: `@alxarafe/arp-angular`.

No stable public API or published package is available yet.
